# 微信小程序申请与发布说明

截至 2026-05-27，申请和发布请以微信公众平台后台为准。官方入口：

- 微信公众平台：https://mp.weixin.qq.com/
- 小程序开发文档：https://developers.weixin.qq.com/miniprogram/dev/framework/
- 微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 1. 准备资料

企业/团队建议提前准备：

- 未注册过公众平台、小程序、开放平台的邮箱。
- 主体资料：营业执照、统一社会信用代码、管理员身份证明、管理员微信。
- 小程序名称、头像、简介、服务类目。
- 如涉及联网服务，准备域名、ICP备案/小程序备案相关信息。
- 如涉及支付，准备微信商户号与经营资质。

AuraGlam 属于智能硬件/美妆服务演示类，正式发布前应避免医疗功效、诊断治疗、夸大护肤效果等表述。

## 2. 注册小程序账号

1. 打开微信公众平台。
2. 选择“立即注册”。
3. 账号类型选择“小程序”。
4. 填写邮箱并激活。
5. 选择主体类型，按页面要求完成主体信息与管理员验证。
6. 登录小程序后台，进入“设置”完善名称、头像、简介、服务类目。

注册完成后获取 `AppID`：小程序后台进入“开发管理/开发设置”，复制 AppID。把本项目 `project.config.json` 中的 `appid` 从 `touristappid` 替换为正式 AppID。

## 3. 开发者配置

1. 在小程序后台进入“成员管理”，添加开发者/体验者。
2. 在“开发管理/开发设置”配置服务器域名、上传下载域名、业务域名。
3. 下载安装微信开发者工具。
4. 用管理员或开发者微信扫码登录。
5. 导入本项目目录，选择正式 AppID。

当前原型是纯前端演示，不依赖后端域名；如果后续接入多模态大模型、云存储视频、账号系统，需要补充合法域名和 HTTPS 接口。

## 4. 上传体验版

1. 在微信开发者工具中确认页面可预览。
2. 点击“上传”。
3. 填写版本号，例如 `0.1.0`。
4. 填写项目备注，例如“AI定妆演示原型”。
5. 回到小程序后台，在“版本管理”中找到开发版本。
6. 设为体验版，添加体验成员扫码测试。

建议测试清单：

- 首页五个入口可跳转。
- 扫描页摄像头授权失败时能使用样张。
- AI 定妆页生成后可显示视频或封面。
- 执行页开始、暂停、复位状态正常。
- 设备页耗材余量和硬件状态展示正常。

## 5. 提交审核

1. 小程序后台进入“版本管理”。
2. 选择体验稳定的开发版本，点击“提交审核”。
3. 选择服务类目，填写功能页面和测试说明。
4. 上传必要资质材料。
5. 等待审核结果，按驳回原因修改后重新提交。

AuraGlam 的审核说明建议写清楚：这是智能美妆机器人控制与演示界面，当前 AI 定妆视频为固定演示素材，未提供医疗诊断、治疗建议、真实功效承诺。

## 6. 发布上线

审核通过后，在“版本管理”点击“发布”。发布后建议继续检查：

- 小程序名称、头像、简介是否与实际功能一致。
- 隐私保护指引是否覆盖摄像头、录音、图片选择、用户输入等场景。
- 如保存用户照片或语音，需要明确告知用途、存储周期、删除方式。
- 如果使用云端大模型处理人脸图像，应在隐私政策中说明处理方、处理目的、撤回授权方式。

## 7. 备案与合规提醒

微信小程序在中国大陆上线通常需要按后台要求完成备案或关联已有备案信息。备案入口和材料要求可能随政策变化调整，请以微信公众平台后台提示为准。

本项目涉及人脸图像、语音输入、妆容推荐，正式产品需要特别注意：

- 摄像头和录音权限只在明确功能中触发。
- 人脸图片、点云、肤况数据属于敏感个人信息，需取得单独同意。
- 不宣传“医美级”带来的治疗效果；“医美级力控”可作为工程精度描述，但不要暗示医疗器械资质。
- AI 生成妆效应标注为效果预览，避免承诺与真实上妆完全一致。
